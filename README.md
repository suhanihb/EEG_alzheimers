# EEG-Based Classification of Alzheimer's Disease

## Overview
This project studies if resting-state EEG features can be used to distinguish individuals with Alzheimer's disease from cognitively normal individuals using machine learning.

## Dataset
**Source:** OpenNeuro ds004504
OpenNeuro dataset **ds004504: A dataset of EEG recordings from Alzheimer's disease, Frontotemporal dementia and Healthy subjects**.

The dataset contains resting-state EEG recordings from three groups:

* Alzheimer's disease (AD)
* Frontotemporal dementia (FTD)
* Cognitively normal (CN)

The initial analysis will focus on **AD vs. CN**
